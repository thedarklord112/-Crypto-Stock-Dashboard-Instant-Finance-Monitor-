> A fast, modern financial monitoring dashboard contained within a **single autonomous file**. Instantly track top live asset metrics and interactive price trends right in your browser.

---

## 🚀 Key Features

- 🟢 **Live Market Streaming:** Pulls exact real-time prices, market cap data, and changes directly via the **CoinGecko API**.
- 📊 **Dynamic Sparkline Charts:** Draws stunning 7-day visual financial trend graphs using **Chart.js** with smart color-coded status logic (green/red indicators).
- 🕒 **Automated In-Memory Polling:** Background scripts automatically push clean asset update loops every 60 seconds without freezing UI interactions.
- ⚡ **Zero Setup Friction:** Completely client-side execution. No Node servers, terminal configurations, or databases required.

---

## 🔧 Installation & Launch

1. Download or copy the `index.html` file into your computer.
2. Double-click `index.html` or open it natively using **Google Chrome**.
3. Explore live asset charts immediately.

---

## 🛠️ Built With

- **Vanilla JavaScript** - Clean async API pipelines and browser-native event handler loops.
- **Chart.js** - Robust, high-performance financial data visualizations and canvas gradient fills.
- **Native CSS3** - Custom futuristic dark-mode user interface tokens requiring zero compilation layers.
